# Portfolio site

Static four-page portfolio (Home, About, Skills, Contact), coded from the hi-fi mockups in
`design/mockups/`. Live at https://omgupta0603-creator.github.io/omgupta0603-creator/. GitHub Pages serves the
`gh-pages` branch, which `.github/workflows/publish-site.yml` refreshes from this folder whenever
`docs/` changes on main. No build step is needed to serve it; you can also just open `index.html`.

## What's in here
- `styles.css`: design tokens (navy `#0F172A`, surface `#1E293B`, sky `#38BDF8`, indigo `#818CF8`;
  Plus Jakarta Sans, Inter, JetBrains Mono) and every component
- `main.js`: GSAP motion. Hero wordmark letters rise and drift on scroll, the AI-answer card types
  its query and streams the answer, the greeting rotates through roles, sections reveal on scroll,
  numbers count up, process steps and the experience timeline draw, skill bars fill, the footer
  wordmark rises. Also the mobile menu and the contact form (opens a pre-filled email).
- `js/spotlight.js`: pointer-following card light and lit edge. Vanilla port of the 21st.dev
  "Spotlight" component by kevingirelli.
- `js/marquee.js`: the "Teams I've worked with" and "Optimizing for" strips. Vanilla port of the
  21st.dev "Logo Marquee" component by ddoemonn: eases to a stop on hover or focus, pauses off screen.
- `vendor/`: GSAP 3.12.5 core and ScrollTrigger, served locally

Motion is skipped for visitors with "reduce motion" turned on (the marquees become scrollable
rows), and if the scripts fail to load, all content shows without animation.

## Editing pages
The HTML is generated by `scripts/build_site.py`. Skills, tools, industries, jobs, FAQ and the
rest of the content are lists at the top of that file. Edit, then run from the repo root:

    python3 scripts/build_site.py docs
