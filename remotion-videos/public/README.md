# Static assets

Reference files here with `staticFile()` from `remotion`, e.g. `staticFile("images/logo.png")`.

- `audio/`: music beds, voice-over, SFX (`<Audio>` from `@remotion/media`)
- `images/`: PNG/JPG/SVG/WebP (`<Img>` from `remotion`)
- `fonts/`: local font files (`loadFont()` from `@remotion/fonts`)

`audio/ambient-pad.mp3` is a royalty-free tone pad generated with ffmpeg for the demo.
